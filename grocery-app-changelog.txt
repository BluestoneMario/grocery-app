❯ Build a grocery list web app saved as index.html (single file, no backend     
  needed).                                                                      
                                                                                
  Core features:                                                                
  - Add and delete grocery items                                                
  - Check items off as you shop                                                 
  - Automatically sort the list based on historical check-off patterns across   
  sessions                                                                      
  - Save all data (items + sort history) in localStorage so it persists between 
   sessions                                                                     
  - Mobile-friendly design since this will be used on a phone in a store        
                                                                                
  Sorting logic:                                                                
  - Normalize each item's check-off position per session: position / total      
  items checked                                                                 
    that session (e.g. 2nd out of 10 = 0.2)                                     
  - Average normalized scores across sessions to determine sort order (0.0 =    
  top of                                                                        
    store, 1.0 = bottom)                                                        
  - Only apply historical sorting if an item has been checked off in at least 2 
   sessions.                                                                    
    Until then, use the manually seeded zone score as a placeholder             
  - If an item has no history and no zone was set, default score is 1.0 (bottom 
   of list)                                                                     
                                                                                
  Adding new items:                                                             
  - When adding an item, show a zone picker with 4 options: Entrance / Middle / 
   Back /                                                                       
    Checkout — these seed the initial sort position (mapped to scores 0.1 / 0.4 
   / 0.7 /                                                                      
    0.9) until real session history takes over                                  
  - Zone selection is optional — skipping it defaults to 1.0                    
                                                                                
  End of trip:                                                                  
  - A clearly visible "Done Shopping" button records the check-off order from   
  the current                                                                   
    session into each item's history, then unchecks all items for the next trip 
  - Items that were not checked off this session do not get a data point        
  recorded for                                                                  
    that session                                                                
                                                                                
  UI:                                                                           
  - Clean, minimal design                                                       
  - Large tap targets for checkboxes (mobile-first)                             
  - Show a small visual indicator on each item for whether it's sorting by      
  historical                                                                    
    data or seeded zone (e.g. a subtle icon or color difference)

  Here's what was implemented:                                                   
                                                                                 
  Reorder mode toggle — a ☰ icon button in the header row, shown whenever the                                                                                    
  list─has─≥2─items.─Clicking─it─toggles─reorder─mode─(amber─highlight─when──────
  active). Switching to Recipes view exits reorder mode automatically.           
                                                                                 
  In reorder mode — each unchecked item swaps its checkbox/note/delete buttons   
  for a drag handle. Checked items (already in cart) keep their normal controls  
  and aren't draggable.                                                          
                                                                                 
  Pointer drag — works for both touch and mouse via pointer events. On drag start
   a floating clone appears at the item's position and follows the cursor; the
  original item turns semi-transparent and repositions in the DOM as you drag    
  (showing the exact drop slot). On release the DOM order is read back into    
  state.items and saved.

  History isolation — drag reorder only touches state.items array order.         
  itemHistory scores are never read or written during a drag. The only time
  scores update is inside recordTrip() when "Confirm and Remember" is pressed.   
                                                                               
  Score-based insertion — new items (added manually or via a recipe) are no      
  longer appended. insertItem() places them before the first unchecked item whose
   score exceeds theirs, so the list stays in a sensible order without forcing   
  the user to manually place every new item.                                   

  One-time migration — on first load after this update, existing items (stored in
   random insertion order) are sorted by score once and saved, giving a clean
  starting point.
